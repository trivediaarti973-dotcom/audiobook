# Text to Audiobook (Python)

Converts a text file into an MP3 audiobook using Google Text-to-Speech (gTTS).
Supports English, Hindi and Korean.

## How to run
pip install -r requirements.txt
python3 audiobook.py

Put your text in book.txt. The program saves audiobook.mp3.

## What I learned
- Reading files in Python
- Using an external library (gTTS)
- Text-to-speech for multiple languages
